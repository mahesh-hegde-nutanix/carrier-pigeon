# Project Information
Pigeon is a VSCode extension to allow using LLM Chat UIs efficiently. In many cases users do not have access to an API.

Pigeon makes it easy to supply repo context to chat tools, and apply diffs back from chat UI to the repo / workspace.

# Rules
* Before adding any dependency, take confirmation from the user. NPM ecosystem is very dangerous. Restrict yourself to reputable and self-contained dependencies.
* Performance and simplicity are important considerations. Push back against any change which might significantly affect these qualities.
